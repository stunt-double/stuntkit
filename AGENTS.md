# Agent instructions

## Public repository

This is a public repository. Everything pushed here (commits, branches, PRs, comments) is visible to anyone.

- Do not mention Claude, Claude Code or any other AI assistant in PR titles, PR descriptions, PR comments, review replies, commit messages or code comments.
- Do not include links to Claude sessions (e.g. `claude.ai/code/session_...`) anywhere.
- Do not add AI attribution lines such as "Generated with Claude Code", `Co-Authored-By: Claude` or `Claude-Session:` trailers.
- Do not include internal hostnames, credentials, tokens or other private context.
